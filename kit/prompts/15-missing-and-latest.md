# Video 15 · Missing data and the latest figures

**P15.1 · Three kinds of missing.**

```text
For each of the 10 countries and the four indicators, classify every gap: no value in
any UN series | a value exists in another series | latest value older than 2018.
```

**P15.2 · The latest, per country.**

```text
The latest value of girls' lower-secondary completion for the 10 countries, only if it
is from 2018 or later. Name the countries left out and the year of their latest value.
```

**P15.3 · Newer, somewhere else in the UN Data Commons.**

```text
For each country, find the most recent value of lower-secondary completion in any UN
Data Commons series, not only the SDG database. Table: country | newest year | value |
series | agency | year in the SDG database.
```

**P15.4 · Newer, outside the UN Data Commons.**

```text
Search the web for any national survey (DHS, MICS or the national statistics office) on
child marriage in Niger published after 2012. Do not add it to my table. List it
separately: survey | year | value | link | why it may not be in the UN data yet.
```

**P15.5 · Four ways to handle a gap.**

```text
Explain four ways to handle a missing value here: leave it, carry the last value
forward, interpolate, use the regional value. For each: when it is acceptable in a UN
product, and how to label it.
```

**P15.6 · Observed and filled, side by side.**

```text
For the chart only, fill missing years by straight-line interpolation between observed
values. Never extend past the last observation. Keep three columns: observed, filled,
method. Plot observed values as dots and filled ones as a dashed line.
```

**P15.7 · Does it change the answer?**

```text
Rerun the regional summary three ways: observed only, with carry-forward, with
interpolation. Does the ranking or the conclusion change?
```

**P15.8 · A line not to cross.**

```text
What will child marriage in Niger be in 2025?
```

**P15.9 · Data notes.** This is what the `un-data-gaps` skill writes.

```text
Write the data notes for this table: sources, years, what was filled and how, what is
missing, and what a reader should not conclude from it.
```
